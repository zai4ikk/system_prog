Описание
Этот репозиторий содержит основные команды Linux и скрипты для работы с файлами, пользователями и группами, а также для выполнения различных системных операций. В репозитории также представлено задание на создание Bash-скрипта, который будет автоматически выполнять определённые действия.

Содержание
Основные команды Linux
Работа с архивацией файла
Задание: создание скрипта на языке Bash
Управление пользователями и группами
Чтение и вывод содержимого файла
Создание и запись в файл
Запуск команды в терминале
Получение информации о системе
Управление процессами
Задание список студентов
